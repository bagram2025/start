README.md для AI-помощника Бусера

```markdown
# 🤖 Бусер — AI-администратор сервера

Терминальный AI-помощник для управления Linux-сервером. Читает логи, проверяет статусы служб, выполняет bash-команды и объясняет ошибки. Работает через g4f — **без API-ключа и регистрации**.

## 🚀 Возможности

- 📊 **Статус сервера** — сводка о диске, памяти, процессах, службах
- 📋 **Логи** — чтение логов PostgreSQL, Nginx, Redis, SSH и любых других служб
- ⚙️ **Bash-команды** — выполнение любых команд через `!`
- 🧠 **AI-анализ** — Бусер анализирует состояние сервера и объясняет ошибки
- 💬 **Диалог** — можно задавать вопросы на русском языке

## 🛠️ Стек

- **Python 3**
- **g4f** (GPT-4o-mini, бесплатно, без ключа)
- **Bash** (systemctl, journalctl, ss, df, free, ps)
- **Redis** (опционально, для кэширования)
- **PostgreSQL** (опционально, для хранения истории)

## 📋 Требования

- VPS с Ubuntu/Debian
- Python 3.8+
- Доступ в интернет (для g4f)

## ⚙️ Установка

```bash
# Клонируйте репозиторий
git clone git@github.com:yourname/buser.git
cd buser

# Запустите установку и деплой
chmod +x run_admin.sh
./run_admin.sh
```

Скрипт сам установит Python, виртуальное окружение, библиотеку g4f и запустит Бусера.

📋 Команды

Команда Описание
статус Полная сводка о сервере
логи Логи PostgreSQL
логи nginx Логи веб-сервера
логи ssh Попытки входа по SSH
логи redis Логи Redis
память Использование RAM
диск Свободное место на диске
процессы Топ-5 процессов по CPU
порт 5432 Проверка порта
!команда Выполнить bash-команду
любой вопрос Спросить AI о сервере
help Все команды
exit Выход

🔒 Безопасность

· AI не выполняет bash-команды сам — только через явную команду !
· Логи SSH помогают отслеживать попытки входа
· Все команды выполняются с правами текущего пользователя
· Для опасных команд (sudo, rm -rf) требуется подтверждение

### README.md для Redis-демо

# ⚡ Redis Demo — тест-драйв возможностей

Демонстрация всех основных структур данных Redis: строки, хэши, списки, множества, сортированные множества и кэширование. Один файл, запуск одной командой.

## 🚀 Что демонстрирует

- 📝 **Строки (Strings)** — базовые операции, TTL, счётчики
- 🗂️ **Хэши (Hashes)** — хранение объектов с полями
- 📋 **Списки (Lists)** — очереди и логи
- 🔖 **Множества (Sets)** — уникальные значения, теги
- 🏆 **Сортированные множества (Sorted Sets)** — рейтинги
- ⚡ **Кэширование** — сравнение скорости запроса к «медленной БД» и к Redis

## 🛠️ Стек

- **Python 3**
- **redis-py**
- **Redis**

## 📋 Требования

- Установленный и запущенный Redis
- Python 3.8+

## ⚙️ Установка и запуск

```bash
# Клонируйте репозиторий
git clone git@github.com:yourname/redis-demo.git
cd redis-demo

# Запустите (установит окружение и библиотеки)
chmod +x run_redis_demo.sh
./run_redis_demo.sh
```

Или вручную:

```bash
pip3 install redis
python3 redis_demo.py
```
